# Static Dashboard assets

The Dashboard summary cards, status counts, January 2025 dates and three crop rows are static examples supplied by the UI reference. They do not read or represent live account data. Status pills are display-only; View All Crops links to the existing Crop Manager page.

Crop photographs were generated with the built-in ImageGen tool using the imagegen skill. The selected square originals were inspected and exported as 160 × 160 WebP thumbnails for this project.

## Final prompts and saved paths

### wheat

Saved asset: `public/images/account/dashboard/wheat.webp`

Use case: photorealistic-natural. Asset type: square crop thumbnail for a farming dashboard. Primary request: a crisp realistic close-up photograph of ripe golden wheat ears growing upright in a wheat field. Composition: one recognizable crop fills the square frame, uncluttered softly blurred farmland background, strong subject readability at 48 pixels. Natural daylight, realistic textures and colors. No people, text, labels, border, logos or watermark. Square image.
